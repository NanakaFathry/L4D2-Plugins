插件我只在sm1.12-7210上测试使用没啥问题，
在sm1.11-6970成功编译但是未测试（我想应该也没啥问题），
若有问题可丢iss探讨。

本插件主要用于测试两点间距/两点流程间距/所处坐标/所处流程/不同位置下的伤害测试等,
详情可见插件源码注释.

插件指令：
!si :打开特感生成菜单,可冻结特感,高亮特感,显示对特感造成的伤害/总伤,玩家穿墙功能.
!biaoji / !bj :打开传送/标记栏,方便在两点间互相传送等.
!bjcur :显示当前所在坐标/最近经过坐标的地图流程位置,地图总流程,地图流程百分比.

!biaoji1 / !bj1 :标记点位1,显示此点坐标,所在流程
!biaoji2 / !bj2 :标记点位2,显示此点坐标,所在流程
若两点都存在,会自动计算出两点间距和两点流程间距
